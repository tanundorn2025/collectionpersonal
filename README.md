# Dashboard ยอดจัดเก็บ (ภาค / กลุ่ม / พนักงานรายคน)

ไฟล์เดียว `index.html` เปิดด้วยเบราว์เซอร์ได้เลย (ต้องมีอินเทอร์เน็ต เพราะโหลด Chart.js และ SheetJS จาก CDN)

## ฟีเจอร์
- ตัวกรอง เดือน / ภาค / กลุ่ม
- KPI, กราฟแนวโน้ม, เปรียบเทียบรายภาค, อันดับพนักงานและกลุ่ม
- วิเคราะห์พนักงานรายคน: % ค่างวด (มูลค่า) เทียบ % สัญญา (จำนวน), จัดกลุ่มผลงาน 4 แบบ, แนวโน้มเพิ่ม/ลด
- ธีม 9 แบบ, ขยายกราฟเต็มจอ, ซ่อนนามสกุลบางส่วน (PDPA)
- อัพโหลดไฟล์ .xlsx / .csv ใหม่เพื่ออัพเดทข้อมูล (เก็บในเบราว์เซอร์ของผู้ใช้)

## รูปแบบไฟล์ข้อมูลที่อัพโหลด
คอลัมน์: เดือน, พนักงานจัดเก็บที่รับผิดชอบ, ภาค, กลุ่ม, สัญญา ทั้งหมด, สัญญาที่เก็บได้, %สัญญาที่เก็บได้, เป้าค่างวด, เก็บได้ค่างวด, % ที่เก็บได้

## ข้อควรระวัง (PDPA)
`index.html` มีข้อมูลตั้งต้นรวมชื่อเต็มพนักงานฝังอยู่ในไฟล์ การซ่อนนามสกุลทำเฉพาะที่หน้าจอ
หากเผยแพร่ขึ้น repo สาธารณะหรือ GitHub Pages ให้ตัดข้อมูลส่วนบุคคลออกก่อน หรือใช้ private repo
